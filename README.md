## About me

I'm a full-stack developer focused on **software engineering, backend systems, applied AI and process automation**. I build web applications and services from requirements and domain modeling through implementation, testing, documentation and deployment preparation.

My core stack includes **Python (FastAPI), Java (Spring Boot), TypeScript, React, Next.js and SQL**. I also bring hands-on experience in IT infrastructure, Linux/Windows environments, networking, Docker and virtualization. That combination shapes how I approach reliability, maintainability and the whole lifecycle of an application.

I develop independent software projects and I'm building **B. Industries**, a solo software studio offering websites, custom applications, integrations and automation. The studio is a current initiative—not a claim of a larger team or a separate history of paid contracts.

I use AI-assisted development tools when appropriate, with responsibility for reviewing implementation decisions, tests and documentation. My interests include **full-stack, backend and AI application engineering**, including remote and international opportunities.
